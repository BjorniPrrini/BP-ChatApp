# BP-Chat diagram exports

These SVG files are full-size, scalable exports corresponding to the Mermaid diagrams in the repository-root `README.md`.

- Keep the Mermaid source in `README.md` as the editable source of truth.
- The SVGs are static vector files intended for opening separately, zooming, printing, and inspecting detailed class names and dependency arrows.
- When changing a Mermaid diagram, regenerate its matching SVG so the two versions stay consistent.

The sequence diagrams retain the usual horizontal participant lanes because they represent message order over time. The class and dependency diagrams prioritize a top-to-bottom layout for easier navigation.
